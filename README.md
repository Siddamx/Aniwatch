# AnimeVerse 🎌

A React + Vite anime watchlist frontend.

## Included anime
- Naruto
- Naruto Shippuden
- Jujutsu Kaisen
- Demon Slayer
- Attack on Titan
- One Piece

## Features
- Search anime
- Genre filters
- Watchlist with LocalStorage
- Details modal
- Responsive design

## Run
```bash
npm install
npm run dev
```
